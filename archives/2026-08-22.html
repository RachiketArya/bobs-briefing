🔒 Security · Data Retention

OpenAI reaffirms Zero Data Retention, previews "Private Safety Processing"

OpenAI restated Zero Data Retention (ZDR) for eligible API customers and previewed Private Safety Processing — running advanced abuse/safety checks without the provider retaining customer data for it. Aimed squarely at regulated enterprise buyers who've been blocked by data-residency and retention concerns.

🏦 Aspire Relevance
If Aspire uses or evaluates OpenAI API products, this is the exact clause vendor-risk and compliance need on file: confirm ZDR eligibility criteria apply to our contract tier, and ask whether Private Safety Processing changes our DPA obligations before assuming "zero retention" covers safety scanning too.

📊 Industry · Market Share

OpenAI is gaining on Anthropic with business users, new data shows

Fresh enterprise-adoption data shows OpenAI clawing back business-user share from Anthropic. The more telling signal: companies are flopping between vendors every time a new frontier model drops — a volatility pattern that should worry both labs' investors about how "sticky" enterprise AI spend actually is.

Vendor lock-in risk cuts both ways here — if enterprise AI spend is this switchy industry-wide, build any AI vendor contract at Aspire with short renewal cycles and explicit exit/portability clauses rather than assuming a multi-year commitment is safe.

🧠 Research · Agent Infra

Nvidia: the harness, not the model, is now the real hero

Nvidia research found agents can perform reliably even with a mediocre underlying model, provided the surrounding harness — tool orchestration, guardrails, fine-tuned control loops — is solid. It's a direct challenge to "just wait for the next frontier model" thinking for production agent deployments.

For any internal AI agent work, this argues for investing in the orchestration/guardrail layer (audit logging, approval gates, retry/fallback logic) rather than betting governance and reliability entirely on model choice — the harness is the actual control point regulators and auditors will ask about.

💰 Funding · Infrastructure

Starcloud raises $250M for orbital data centers as launch capacity dries up

Starcloud closed a $250M round to build data centers in orbit, betting that terrestrial power and cooling constraints will push AI compute off-planet. The raise signals a coming scramble for launch slots as more players chase the same idea.

Early-stage signal, not an action item — but worth tracking as one more data point on how AI compute scarcity is reshaping infrastructure costs, which eventually feeds through to API pricing for everyone downstream.
